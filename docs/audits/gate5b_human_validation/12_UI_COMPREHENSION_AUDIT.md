## 1. 5-Second Information Retrieval Test

In automated viewport testing, all Level 1/2/3 parameters are retrieved in $< 2$ seconds without user scrolling or interaction:
- **Status:** `✓ FEASIBLE`
- **Deadline:** `LEAVE BY T+44:21` (Dominant 36px font)
- **Arrival:** `Flood reaches route: T+60:00`
- **Limiting Segment:** `Limiting part of route: R02`

## 2. 10-Second Mental Reconstruction
Opening the **`[WHY?]`** accordion allows immediate mental reconstruction of the governing equation:
$$60:00 - 12:39 - 03:00 = 44:21$$
Eliminates mental arithmetic and ambiguity.
