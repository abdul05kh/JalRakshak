## Status Classification Key
- `IMPLEMENTED`: Functionality is fully implemented, mathematically verified, and covered by automated test suites.
- `PARTIALLY_IMPLEMENTED`: Architectural abstraction and testing pipelines are complete; execution requires external cloud credentials (e.g. Google Earth Engine Service Account).
- `NOT_SCIENTIFICALLY_DEFENSIBLE_TO_FAKE`: Requirement depends on proprietary external solvers or unavailable structural surveys; truthful `NOT_CONFIGURED` status is enforced rather than fabricating synthetic data.
