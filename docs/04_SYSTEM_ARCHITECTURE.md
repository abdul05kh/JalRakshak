# 04 — System Architecture

Modular architecture:
- **Frontend:** React, TypeScript, Vite, MapLibre GL JS / Leaflet, TanStack Query, Light Theme.
- **Backend:** FastAPI, Pydantic, SQLAlchemy, GeoPandas, Shapely, NetworkX, Rasterio.
- **Database:** SQLite / PostgreSQL + PostGIS.
- **Hydraulic Layer:** HEC-RAS 2D Adapter interface with verified precomputed scenarios.
