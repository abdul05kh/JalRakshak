# 07 — Frontend Design System

Operational Emergency Planning Instrument:
- White/light neutral canvas (`#f8fafc` background, `#0f172a` primary text, `#2563eb` accent).
- No dark mode, neon palettes, glassmorphism, or AI buzzwords.
- Information hierarchy: Route Status > Departure Deadline > Travel Time > Limiting Segment > Explanation.
- Map-first layout with persistent legend and provenance drawer.
