# Coupled Hydrodynamic Boundary Condition Formulation

## 1. Upstream Hydrograph Inflow
At the dam breach cross-section $\Gamma_{in}$:
$$Q(t) = Q_{breach}(t)$$
$$\vec{v} \cdot \hat{n} = \frac{Q(t)}{A_{cross}(h)}$$

## 2. Downstream Free Outflow
At Devprayag valley boundary $\Gamma_{out}$:
$$\frac{\partial h}{\partial n} = 0, \quad \frac{\partial \vec{v}}{\partial n} = 0$$
Using normal depth condition with energy slope $S_0 = 0.0035$.
