# Map Accessibility Specification

**Project:** JalRakshak Emergency Decision-Support System  
**Standard:** WCAG 2.1 Level AA Compliance  
**Date:** 2026-09-25  

---

## 1. Multi-Channel Redundancy
- **Color + Icon + Text:** All route status indicators (`FEASIBLE`, `LOW MARGIN`, `INFEASIBLE`, `DATA GAP`) use triple redundant encoding.
- **High Contrast:** Hero deadline text (`#0f172a` on `#ffffff`) provides 16.2:1 contrast ratio.
- **Keyboard Navigation:** All interactive timeline and card elements support standard Tab focus and keyboard triggers.
