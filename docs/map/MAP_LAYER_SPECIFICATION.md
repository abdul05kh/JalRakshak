# Map Layer Specification

**Project:** JalRakshak Emergency Decision-Support System  
**Date:** 2026-09-25  

---

## 1. Operational Layers (Default Visible)
1. **Inundation Extent:** Semi-transparent blue wavefront polygon (`#0284c7`, opacity 0.45).
2. **Selected Route:** High-contrast royal blue polyline (`#1d4ed8`, weight 5.5).
3. **Limiting Segment:** High-contrast crimson polyline (`#dc2626`, weight 7.5).
4. **Origin Settlements:** Amber circular markers (`#d97706`).
5. **Destination Shelters:** Forest green shelter markers (`#15803d`).

## 2. Optional Layers
- Background Road Network (Gray `#94a3b8`).
- 150m Road Corridor Buffer Zones.
- Elevation Contour Relief Overlay.
