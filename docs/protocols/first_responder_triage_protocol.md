# First Responder Flood Medical Triage Protocol (START)

## 1. Initial Assessment (Under 30 seconds per casualty)
1. **Respirations**:
   - Absent $\to$ Open airway $\to$ If still absent: **BLACK (Deceased)**.
   - $> 30\text{ breaths/min}$ $\to$ **RED (Immediate)**.
2. **Perfusion (Capillary Refill / Radial Pulse)**:
   - Capillary refill $> 2\text{ sec}$ or absent pulse $\to$ **RED (Immediate)**.
3. **Mental Status**:
   - Cannot follow simple commands $\to$ **RED (Immediate)**.
   - Can follow commands $\to$ **YELLOW (Delayed)**.
4. **Walking Wounded**:
   - Able to walk to high-ground assembly $\to$ **GREEN (Minor)**.
