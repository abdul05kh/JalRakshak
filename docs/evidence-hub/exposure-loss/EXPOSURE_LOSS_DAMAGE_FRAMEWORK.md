**JALRAKSHAK — EXPOSURE, LOSS & DAMAGE FRAMEWORK**
JalRakshak SIH'26 — Evidence Hub

# Purpose

Exposure/loss should remain a structured framework unless authoritative inventories, vulnerability functions, values and validation data exist.

# Exposure layers

- Population/settlements where sourced
- Buildings/critical infrastructure where legitimately sourced
- Roads
- Evacuation shelters/assembly areas
- Administrative/contextual GIS

# Requirements for defensible loss analysis

- Exposure inventory and asset classes.
- Hazard intensity variables such as depth/velocity/duration.
- Appropriate vulnerability/fragility functions.
- Replacement values or explicit non-monetary consequence scale.
- Temporal context where relevant.
- Validation or benchmark evidence.

# Current boundary

Describe this as an exposure/loss framework, not a validated financial damage predictor. Unsupported hard-coded damage curves or accuracy percentages must not be presented as established science.

## Status Notice
This subsystem is strictly an **Exposure Assessment Framework**. It does not constitute an empirically validated structural damage or financial loss prediction engine.
